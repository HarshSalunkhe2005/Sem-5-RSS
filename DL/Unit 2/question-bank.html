Group A

Activation functions

Question Bank Q56–73

Q56What is an activation function?

A function applied to a neuron's weighted sum (z) that produces its output — deciding whether/how strongly the neuron "fires", and introducing non-linearity into the network.

Q57Why are activation functions necessary?

Without one, every layer is just a linear transform, and stacking linear layers collapses mathematically into a single linear layer — no matter how deep, the network could only learn straight-line relationships.

Q58What if every layer used only a linear activation?

The whole network reduces to one big linear function of the input — depth would add zero representational power over a single-layer linear model.

Q59Explain the sigmoid function.

σ(z)=1/(1+e⁻ᶻ), an S-shaped curve bounded in (0,1), smooth and differentiable everywhere, steepest at z=0 — used historically as the default neuron activation and still standard for binary-classification outputs.

Q60Explain the tanh function.

tanh(z)=(eᶻ−e⁻ᶻ)/(eᶻ+e⁻ᶻ), a rescaled sigmoid bounded in (−1,1) and zero-centered — the zero-centering usually makes it converge faster than sigmoid in hidden layers, though it still saturates at the extremes.

Q61Explain ReLU.

ReLU(z)=max(0,z) — identity for positive inputs, exactly zero for negative ones. Cheap to compute, doesn't saturate for z>0, and is the default choice for hidden layers in modern networks.

Q62Explain Leaky ReLU.

Leaky ReLU(z) = z if z≥0, else αz (small α like 0.01) — lets a small gradient leak through for negative inputs instead of going to exactly zero, fixing the dying-ReLU problem.

Q63Compare sigmoid, tanh, ReLU and Leaky ReLU.

Sigmoid: (0,1), saturates both ends, not zero-centered. Tanh: (−1,1), saturates both ends, zero-centered. ReLU: [0,∞), no saturation for positive z, can "die" for negative z. Leaky ReLU: same as ReLU but never fully dies. ReLU/Leaky ReLU are preferred in hidden layers of deep nets; sigmoid is reserved for binary output layers.

Q64What is the vanishing-gradient problem?

In deep networks, gradients are products of many local derivatives via the chain rule. Sigmoid/tanh derivatives are always <1 (often ≪1 in saturated regions), so multiplying many of them together shrinks the gradient toward zero by the time it reaches early layers — those layers barely learn.

Q65Why does ReLU generally beat sigmoid in hidden layers?

ReLU's derivative is exactly 1 for any positive input (no shrinkage), so gradients pass through unattenuated across many layers — unlike sigmoid, whose derivative is always ≤0.25 and shrinks fast when stacked.

Q66What is the dying-ReLU problem?

If a neuron's pre-activation z stays negative (e.g. from a bad weight update), ReLU outputs 0 and its gradient is exactly 0 too — the neuron stops updating and is permanently "dead," contributing nothing forever after.

Q67When would sigmoid be appropriate?

In the output layer of a binary classifier, where a (0,1) output can be read directly as a probability of the positive class.

Q68Why is softmax used for multiclass classification?

Softmax converts a vector of raw scores (logits) into a probability distribution over all classes (all values in (0,1), summing to 1) — exactly the format needed to pick the most likely class and to use categorical cross-entropy as the loss.

Group B

Loss functions

Question Bank Q74–93

Q74What is a loss function?

A function that measures how far a single prediction is from its true label — the quantity gradient descent tries to minimize.

Q75Why is a loss function necessary?

Without a numeric measure of "how wrong" a prediction is, there's nothing for backpropagation to differentiate and nothing for gradient descent to minimize — the loss is what turns training into an optimization problem.

Q76Explain Mean Squared Error.

MSE = average of (actual − predicted)² over all samples. Penalizes larger errors disproportionately (squaring), standard for regression problems.

Q77Explain Binary Cross-Entropy.

BCE = −[y·log(ŷ) + (1−y)·log(1−ŷ)] — measures the "distance" between a true binary label and a predicted probability; heavily penalizes confident wrong predictions.

Q78Explain Categorical Cross-Entropy.

CCE = −log(ŷ_true class) — the multiclass generalization of BCE; with one-hot labels, only the predicted probability assigned to the correct class contributes to the loss.

Q79Why is cross-entropy preferred over MSE for classification?

Cross-entropy's gradient stays large when the prediction is confidently wrong (no vanishing-gradient interaction with a saturated sigmoid/softmax), whereas MSE combined with sigmoid produces very small gradients in that same regime, slowing learning right when it matters most.

Q80Which loss for binary, multiclass, and regression?

Binary classification → Binary Cross-Entropy. Multiclass classification → Categorical Cross-Entropy (with softmax). Regression → Mean Squared Error (or MAE).

Q81Relationship between logits, sigmoid, softmax, cross-entropy?

Logits are the raw, unbounded pre-activation scores from the last layer. Sigmoid (binary) or softmax (multiclass) squashes logits into valid probabilities. Cross-entropy then measures the gap between those predicted probabilities and the true label — the three form a standard pipeline: logits → probabilities → loss.

Q82Loss vs. cost function?

Loss is the error on a single training example; cost (or empirical loss) is the average loss across the entire training set (or batch) — the quantity actually minimized during training.

Q83What is empirical risk minimization?

Training a model by minimizing the average loss (empirical risk) over the observed training data, as a stand-in for minimizing the true (unknown) expected loss over the whole data distribution.

Q88Explain forward propagation.

The process of passing an input through the network layer by layer — each layer computing a weighted sum plus bias, then an activation — until the output layer produces the final prediction.

Q89Equations for forward propagation through a two-layer network.

z1 = W1·x + b1, a1 = f(z1) then z2 = W2·a1 + b2, ŷ = f(z2) — each layer's output becomes the next layer's input.

Q90Role of weights and biases?

Weights control how strongly each input influences a neuron (learned "importance"); the bias shifts the decision boundary/activation threshold independently of the inputs, so the boundary isn't forced through the origin.

Q91How does a network transform data through layers?

Each layer applies a linear transform (weighted sum + bias) followed by a non-linear activation, progressively remapping the input into representations that are easier for the next layer — and ultimately the output layer — to use.

Q92What is a logit?

The raw, unbounded output of a layer before a squashing activation (sigmoid/softmax) is applied — i.e. the pre-activation z feeding into the final classification activation.

Q93Weighted sum vs. activated output?

The weighted sum (z = Σwx+b) is the raw linear combination; the activated output (a = f(z)) is what's actually passed to the next layer — the non-linear activation is what separates the two.

Computational graphs & backpropagation

Question Bank Q94–110

Q99What is backpropagation?

The algorithm that computes the gradient of the loss with respect to every weight and bias in a network, by propagating the error backward from the output layer using the chain rule.

Q100Why is the chain rule fundamental to backprop?

A deep network is a composition of many functions (layer after layer); the chain rule is the only way to differentiate a composition of functions, so it's literally the mechanism that makes computing ∂L/∂(any weight) possible.

Q101Explain forward/backprop via a computational graph.

Draw every operation (multiply, add, activation) as a node; forward pass computes and caches every node's value left-to-right; backward pass starts from the loss and multiplies local derivatives node-by-node right-to-left, accumulating the gradient for every parameter.

Q102Derive the gradient of a single neuron w.r.t. its weight.

For z=wx+b, a=f(z), L=loss(a,y): ∂L/∂w = (∂L/∂a)(∂a/∂z)(∂z/∂w) = (∂L/∂a)·f'(z)·x — three local derivatives chained together.

Q103Derive backprop equations for a two-layer network.

Output layer: ∂L/∂z₂ = ∂L/∂ŷ · f'(z₂); ∂L/∂W₂ = ∂L/∂z₂ · a₁ᵀ. Propagate back: ∂L/∂a₁ = W₂ᵀ·∂L/∂z₂. Hidden layer: ∂L/∂z₁ = ∂L/∂a₁ · f'(z₁); ∂L/∂W₁ = ∂L/∂z₁ · xᵀ. Fully worked with real numbers on the Numericals page.

Q104Local gradients vs. global gradients?

A local gradient is one node's own derivative w.r.t. its immediate input (e.g. ∂a/∂z for one activation). The global gradient (∂L/∂w for some weight deep in the network) is the product of every local gradient along the path from that weight to the loss.

Q105What is gradient flow?

How the gradient's magnitude changes as it's propagated backward through many layers — "healthy" gradient flow keeps gradients at a usable scale at every layer; vanishing/exploding gradients are gradient flow gone wrong.

Q106What is the exploding-gradient problem?

The opposite of vanishing gradients: when local derivatives multiply to values >1 repeatedly across many layers, the accumulated gradient grows exponentially large, causing huge, unstable weight updates.

Q107How do activation functions affect gradient propagation?

Their derivative is a multiplicative factor in every chain-rule product along the backward path — sigmoid/tanh derivatives (≤0.25 / ≤1) shrink gradients across layers (vanishing), while ReLU's derivative of exactly 1 (for z>0) lets gradients pass through unshrunk.

Q108Role of the learning rate in backprop?

It scales how big a step each parameter update takes in the direction opposite the gradient (θ←θ−η·∂L/∂θ). Too small → painfully slow convergence; too large → overshooting and unstable/divergent training.
