Sigmoid derivative

σ'(z) = σ(z)(1−σ(z)) for z = 0, 2, −2

zσ(z)σ'(z) = σ(z)(1−σ(z))

Note the symmetry — σ'(z) is identical at z and −z whenever σ(z)+σ(−z)=1. The derivative is largest at z=0 (steepest part of the curve) and shrinks toward the flat tails — the root cause of vanishing gradients.

ReLU

ReLU(z) = max(0,z) for z = [−3, −1, 0, 2, 4]

ReLU outputs: [0, 0, 0, 2, 4] — negatives clipped to exactly 0, positives pass through unchanged.
Leaky ReLU

Leaky ReLU(z) = z if z≥0, else 0.01z — for z = [−3, −1, 0, 2]

Outputs: [−0.03, −0.01, 0, 2] — negatives are scaled down (not zeroed), which keeps a small gradient alive and avoids the "dying ReLU" problem.
Softmax

softmax(z) for z = [2, 1, 0] — verify probabilities sum to 1

  • Exponentiate each logite²=7.389, e¹=2.718, e⁰=1.000
  • Sum the exponentials7.389+2.718+1.000 = 11.107
  • Divide each by the sum[7.389/11.107, 2.718/11.107, 1/11.107] = [0.665, 0.245, 0.090]
    • softmax([2,1,0]) ≈ [0.665, 0.245, 0.090] — sums to 1.000 ✓ (largest logit gets the largest, but not all, probability mass)

    Numericals 6–9 · Q84–87

    Loss function calculations

    Mean Squared Error

    y = [1, 0, 1], ŷ = [0.8, 0.2, 0.6]

  • Squared error per sample(1−0.8)²=0.04, (0−0.2)²=0.04, (1−0.6)²=0.16
  • AverageMSE = (0.04+0.04+0.16)/3 = 0.24/3
    • MSE = 0.08
    Binary Cross-Entropy

    y=1, ŷ=0.8

    BCE = −[1·log(0.8) + 0·log(0.2)] = −log(0.8) ≈ 0.2231 (natural log)
    BCE comparison

    y=0 with ŷ=0.2 vs. y=0 with ŷ=0.8

    CaseBCE = −log(1−ŷ)Value
    y=0, ŷ=0.2 correctly leaning 0−log(1−0.2) = −log(0.8)0.2231
    y=0, ŷ=0.8 confidently wrong−log(1−0.8) = −log(0.2)1.6094

    Why the gap: BCE punishes confident wrong predictions far more harshly than mild wrong ones — going from "slightly wrong" (0.22) to "confidently wrong" (1.61) is over a 7× jump, which is exactly the signal gradient descent needs to correct bad confidence fast.

    Categorical Cross-Entropy

    True class = 2, predicted probabilities = [0.1, 0.7, 0.2]

    CCE = −log(p_true class) = −log(0.7) ≈ 0.3567 — only the predicted probability assigned to the correct class matters; the other entries drop out of the formula entirely.

    Graph 5 — dead ReLU

    a=xw+b, h=ReLU(a), L=(h−y)² — x=−2, w=3, b=1, y=2

  • aa = (−2)(3)+1 = −5
  • hh = ReLU(−5) = 0
  • LL = (0−2)² = 4
  • Does the gradient propagate?a=−5<0 → ReLU'(a)=0 → no, blocked
  • ∂L/∂w2(h−y)·ReLU'(a)·x = 2(−2)(0)(−2) = 0

    • This is the "dead ReLU" problem in miniature: once a neuron's pre-activation goes negative, its gradient is exactly zero and no weight below it can learn from this example — motivating Leaky ReLU / ELU as fixes.

    Backpropagation Numerical 1 · Q109

    Single sigmoid neuron, binary cross-entropy

    x=2, w=0.4, b=0.1, y=1    L = −[y·log ŷ + (1−y)·log(1−ŷ)]
  • Pre-activation zz = xw+b = 2(0.4)+0.1 = 0.9
  • Prediction ŷŷ = σ(0.9) = 1/(1+e⁻⁰·⁹) = 0.7109
  • LossL = −log(0.7109) = 0.3412
  • ∂L/∂z (sigmoid + BCE simplifies beautifully)∂L/∂z = ŷ − y = 0.7109 − 1 = −0.2891
  • ∂L/∂w(∂L/∂z)·x = −0.2891 × 2 = −0.5782
  • ∂L/∂b(∂L/∂z)·1 = −0.2891

    • Memorize this simplification — whenever a sigmoid output feeds directly into binary cross-entropy, all the messy σ'(z) terms cancel and ∂L/∂z = ŷ − y. This is why sigmoid+BCE (and softmax+categorical cross-entropy) are paired so often in practice.

    Bonus — two-layer version (Q110 style)

    h=σ(W₁x+b₁), ŷ=σ(W₂h+b₂)    illustrative scalars: x=1, W₁=0.5, b₁=0, W₂=0.5, b₂=0, y=1, L=½(ŷ−y)²
  • Layer 1z₁ = 0.5, h = σ(0.5) = 0.6225
  • Layer 2z₂ = 0.5×0.6225 = 0.3113, ŷ = σ(0.3113) = 0.5772
  • LossL = ½(0.5772−1)² = 0.0894
  • Chain back through both sigmoids∂L/∂ŷ=−0.4228 → ×∂ŷ/∂z₂(=0.2440) → ×∂z₂/∂h(=W₂=0.5) → ×∂h/∂z₁(=0.2350) → ×∂z₁/∂W₁(=x=1)
    • ∂L/∂W₁ ≈ −0.0121 — five multiplications chained end to end; this is exactly why deep stacks are prone to vanishing gradients (multiply enough numbers <1 together and the product shrinks fast).

    Comprehensive worked example · from your professor's slides

    Full network: forward pass → loss → backprop → update

    2 inputs → Hidden(2, ReLU) → Hidden(2, ReLU) → Output(1, Sigmoid), binary cross-entropy loss. Every number below is the actual worked example from the course slides — reproduce this method on any similar architecture and you can handle the exam's "comprehensive problem".

    x₁=0.50, x₂=0.80, y=1, η=0.1
    W₁=[[0.15,0.20],[0.25,0.30]], b₁=[0.10,0.10]
    W₂=[[0.40,0.50],[0.45,0.55]], b₂=[0.20,0.20]
    W₃=[0.60, 0.65], b₃=0.10

    1 · Forward pass

  • Hidden layer 1 (ReLU)z1(1)=0.5(0.15)+0.8(0.25)+0.10=0.375 → a1(1)=0.375
    z1(2)=0.5(0.20)+0.8(0.30)+0.10=0.440 → a1(2)=0.440
  • Hidden layer 2 (ReLU)z2(1)=0.375(0.4)+0.44(0.45)+0.2=0.548 → a2(1)=0.548
    z2(2)=0.375(0.5)+0.44(0.55)+0.2=0.630 → a2(2)=0.630
  • Output (Sigmoid)z3=0.548(0.6)+0.63(0.65)+0.1=0.838 → ŷ=σ(0.838)≈0.698
  • Loss (BCE, y=1)L = −log(0.698) ≈ 0.359

    • 2 · Backward pass

  • Output layer — ∂L/∂z₃ = ŷ−y0.698−1 = −0.302  →  ∂L/∂w₃(1)=−0.302×0.548=−0.1655, ∂L/∂w₃(2)=−0.302×0.630=−0.1901, ∂L/∂b₃=−0.302
  • Gradient handed to Hidden Layer 2∂L/∂a2(1)=−0.302×0.60=−0.1812, ∂L/∂a2(2)=−0.302×0.65=−0.1963
  • Hidden Layer 2 (both z2>0 → ReLU'=1)∂L/∂w2(11)=−0.1812×0.375=−0.0680, ∂L/∂w2(12)=−0.1963×0.375=−0.0736
    ∂L/∂w2(21)=−0.1812×0.440=−0.0797, ∂L/∂w2(22)=−0.1963×0.440=−0.0864
  • Gradient handed to Hidden Layer 1∂L/∂a1(1)=−0.1812(0.4)+−0.1963(0.5)=−0.1706
    ∂L/∂a1(2)=−0.1812(0.45)+−0.1963(0.55)=−0.1895
  • Hidden Layer 1 (both z1>0 → ReLU'=1)∂L/∂w1(11)=−0.1706×0.5=−0.0853, ∂L/∂w1(12)=−0.1895×0.5=−0.0948
    ∂L/∂w1(21)=−0.1706×0.8=−0.1365, ∂L/∂w1(22)=−0.1895×0.8=−0.1516

    • 3 · Gradient descent update (η=0.1)

    w₃(1)_new = 0.60 − 0.1×(−0.1655) = 0.6165    w₃(2)_new = 0.65 − 0.1×(−0.1901) = 0.6690    b₃_new = 0.10 − 0.1×(−0.302) = 0.1302  (every other weight updates the same way: θ_new = θ_old − η·∂L/∂θ)

    The pattern to reproduce on the exam: (1) forward pass layer by layer, caching every z and a; (2) at the output, ∂L/∂z = ŷ−y (for sigmoid+BCE); (3) push that gradient backward, at each ReLU layer multiplying by 1 if z>0 else 0; (4) at each layer, ∂L/∂W = (incoming gradient)·(previous layer's activation)ᵀ; (5) update every parameter with θ ← θ − η·∂L/∂θ.
