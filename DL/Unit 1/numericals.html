Numerical 1

Perceptron output

w₁=0.4, w₂=−0.6, b=0.2, x₁=2, x₂=3    f(z)=1 if z≥0, else 0
  1. Weighted sumz = w₁x₁ + w₂x₂ + b = (0.4)(2) + (−0.6)(3) + 0.2 = 0.8 − 1.8 + 0.2
  2. Simplifyz = −0.8
  3. Apply step functionz < 0 → f(z) = 0
Output ŷ = 0

Numerical 2

Perceptron weight update

w=[0.2, −0.4], b=0.1, x=[1,2], target y=1, η=0.1
  1. Forward pass — weighted sumz = (0.2)(1) + (−0.4)(2) + 0.1 = 0.2 − 0.8 + 0.1 = −0.5
  2. Predicted outputz < 0 → ŷ = 0 (target was 1 — misclassified!)
  3. Error term(y − ŷ) = (1 − 0) = 1
  4. Update weights: w ← w + η(y−ŷ)xw₁ = 0.2 + 0.1(1)(1) = 0.3    w₂ = −0.4 + 0.1(1)(2) = −0.2
  5. Update bias: b ← b + η(y−ŷ)b = 0.1 + 0.1(1) = 0.2
New w = [0.3, −0.2], new b = 0.2

Numerical 5

Decision boundary derivation

z = 4x₁ − 2x₂ + 6
  1. Boundary = where z is exactly 04x₁ − 2x₂ + 6 = 0
  2. Solve for x₂2x₂ = 4x₁ + 6 ⇒ x₂ = 2x₁ + 3
  3. Test a point to find the class-1 side — try origin (0,0)z(0,0) = 0−0+6 = 6 ≥ 0 → class 1
Boundary: x₂ = 2x₁ + 3. The side containing the origin (where x₂ < 2x₁+3) is class 1.

  1. Try b=1: rule is ŷ=1 if x₁+x₂≥1(0,0)→0≥1? No→0 ✓   (0,1)→1≥1? Yes→1 ✓   (1,0)→1≥1? Yes→1 ✓   (1,1)→2≥1? Yes→1 ✓
