Optimization Numericals 4–5 · Q136–137

Momentum & Adam

Numerical 4 — Momentum

gₜ=4, vₜ₋₁=2, β=0.9, η=0.1

Convention used: vₜ = β·vₜ₋₁ + η·gₜ    (then θ ← θ − vₜ)
  • New velocityvₜ = 0.9(2) + 0.1(4) = 1.8 + 0.4 = 2.2
  • Parameter updateΔθ = −vₜ = −2.2 (i.e. θ_new = θ_old − 2.2)
    • vₜ = 2.2, update = −2.2

    Watch the convention: some texts instead write vₜ=βvₜ₋₁+(1−β)gₜ (an exact exponential moving average) and step with θ←θ−η·vₜ separately. Always check which convention a question is using — state it explicitly in your answer, as done above.

    Numerical 5 — Adam

    gₜ=0.4, mₜ₋₁=0.1, vₜ₋₁=0.05, β₁=0.9, β₂=0.999

  • First-moment estimate (momentum)mₜ = β₁mₜ₋₁+(1−β₁)gₜ = 0.9(0.1)+0.1(0.4) = 0.09+0.04 = 0.13
  • Second-moment estimate (magnitude)vₜ = β₂vₜ₋₁+(1−β₂)gₜ² = 0.999(0.05)+0.001(0.16) = 0.04995+0.00016 = 0.05011
  • Bias-corrected estimates (illustrating at t=2, since mₜ₋₁≠0 means t≥2)m̂ = mₜ/(1−β₁ᵗ) = 0.13/(1−0.81) = 0.13/0.19 = 0.6842
    v̂ = vₜ/(1−β₂ᵗ) = 0.05011/(1−0.998001) = 0.05011/0.001999 = 25.07
  • Parameter update (general form)Δθ = −η · m̂ / (√v̂ + ε)
    • mₜ=0.13, vₜ=0.05011, m̂≈0.6842, v̂≈25.07 (at t=2) — plug into Δθ=−η·m̂/(√v̂+ε) once η is specified.

    Notice how large the bias correction is at small t, especially for v̂ — this is exactly why Adam applies it: without correction, the early steps would badly underestimate both moments (since m₀=v₀=0), causing wildly oversized effective steps.

    Regularization Numericals 1–3 · Q154–156

    L1 / L2 penalty calculations

    L2 (Ridge)

    Lₙₐₜₐ=2.5, w=[2,−3,1], λ=0.1 — L = Lₙₐₜₐ + (λ/2)Σwᵢ²

  • Sum of squared weightsΣwᵢ² = 4+9+1 = 14
  • Penalty term(λ/2)(14) = 0.05×14 = 0.7
    • L = 2.5 + 0.7 = 3.2
    L1 (Lasso)

    Lₙₐₜₐ=1.5, w=[2,−4,1], λ=0.2 — L = Lₙₐₜₐ + λΣ|wᵢ|

  • Sum of absolute weightsΣ|wᵢ| = 2+4+1 = 7
  • Penalty termλ(7) = 0.2×7 = 1.4
    • L = 1.5 + 1.4 = 2.9
    L2 gradient

    L(w)=Lₙₐₜₐ(w)+(λ/2)w², ∂Lₙₐₜₐ/∂w=3, w=4, λ=0.2

    ∂L/∂w = ∂Lₙₐₜₐ/∂w + λw = 3 + 0.2(4) = 3 + 0.8 = 3.8

    Dropout Problems 1–2 · Q157–158

    Dropout

    Dropout Problem 1

    10 hidden neurons, dropout probability p=0.4

  • Expected active neurons10 × (1−0.4) = 6
  • Expected dropped neurons10 × 0.4 = 4
  • At inferenceModern (inverted) dropout applies no dropout and no extra scaling at test time — the 1/(1−p) scaling was already applied during training, so the full network is used as-is.
    • ≈6 active, ≈4 dropped during training; full network, unscaled, at inference.
    Dropout Problem 2 — inverted dropout

    h=[2,4,6,8], p=0.5, mask=[1,0,1,0]

  • Apply the maskh⊙mask = [2, 0, 6, 0]
  • Scale by 1/(1−p)[2,0,6,0] / 0.5 = [4, 0, 12, 0]
    • Output = [4, 0, 12, 0] — scaling at train time (inverted dropout) keeps the expected activation magnitude the same whether or not a unit was dropped, so no rescaling is needed at test time.
