# DL Source Materials

Raw source decks pulled from the Moodle course room (`Deep Learning_26-27`), kept here for
reference/provenance. The built notes in `DL/Unit 1`, `DL/Unit 2`, and `DL/Unit 3` are the
self-contained, actually-useful pages — treat this folder as an archive, not something to read
directly.

## official-course/

The professor-assigned deck for each unit, plus the two IIT Madras CS7015 (Mitesh Khapra)
lectures the "M-P Neuron and Perceptron" / "History of Deep Learning" resources link to.
`PPT-MP-Neuron.pptx` and `PPT-Sigmoid-Neuron.pptx` are image-heavy (little extractable text);
the CS7015 PDFs and `PPT-Perceptron.pdf` carry the real content.

## tanveer-lectures/

A second, more detailed lecture set (course instructor Tanveer Ahmed) covering the same topics
from a different angle — DL foundations, M-P Neuron/Perceptron, activation functions, linear
regression, optimizers, backprop and dropout. `McCulloch-Pitts-Neuron.pptx` and
`Optimization-Algorithms.pptx` were the two richest sources used while building the notes.

## zulfikar/

One unique file from a second instructor's section (Dr. Zulfikar Ali Ansari) — his Unit-02,
History of Deep Learning, and other files turned out byte-identical to files already archived
above, so only his distinct Unit-01 is kept here.

## Not archived here

`Unit1_Deep_Learning.pptx`, `Unit 2.pptx`, `Unit 3.pptx`, `Deep_Learning_Numerical_Prep.pdf`,
and `Deep_Learning_Question_Bank(2).docx` were the originally-provided course files (not Moodle
downloads) — kept wherever you already have them, not duplicated into this repo.
