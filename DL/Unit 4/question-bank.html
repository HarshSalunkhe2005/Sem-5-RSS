Group A

Optimization algorithms

Unit 4 Q1–9

Q1Compare batch GD, SGD and mini-batch GD.5 marks

Batch GD uses all N examples per update, ∇L = (1/N)Σ∇Lᵢ: exact, smooth, but one update per epoch and heavy on memory. SGD uses one example (m = 1): N cheap noisy updates per epoch; the noise can help escape saddles but the loss wobbles and needs a decaying α. Mini-batch uses m ≈ 32–256: stable enough, vectorizes on GPUs, and is the default in practice.

Q2Explain SGD with momentum. Write its update rule.5 marks

Momentum keeps a velocity, an exponentially weighted average of past gradients: v ← βv + α∇L, θ ← θ − v. Consistent directions accumulate speed while oscillating components cancel, so it learns faster and with less zig-zag. β = 0.9 gives about 1/(1−β) = 10 steps of memory. Drawback: an extra hyperparameter and possible overshoot.

Q3How does Nesterov Accelerated Gradient differ from momentum?5 marks

NAG evaluates the gradient at the look-ahead point θ − βv instead of the current θ: v ← βv + α∇L(θ − βv), θ ← θ − v. "Momentum acts then looks; Nesterov looks then acts", so it senses an approaching rise early and brakes, giving less overshoot and better convergence on convex problems. Example (L = w², w₀ = 4, α = 0.1, β = 0.9): momentum gives w₂ = 1.84, NAG gives w₂ = 1.984 with a smaller velocity (1.216 vs 1.36).

Q4Explain Adagrad. What is its main drawback?5 marks

Adagrad gives each parameter its own rate: Gₜ = Gₜ₋₁ + gₜ², θ ← θ − αg/(√Gₜ + ε). Rare (sparse) features keep large steps, frequent ones get small steps, and no manual per-parameter tuning is needed. Because Gₜ is a sum that only grows, the effective rate shrinks toward zero, so learning stalls on deep or long training runs.

Q5Explain RMSprop and how it fixes Adagrad.5 marks

RMSprop replaces Adagrad's cumulative sum with an exponentially decaying average: E[g²]ₜ = ρE[g²]ₜ₋₁ + (1−ρ)gₜ², θ ← θ − αg/(√E[g²]ₜ + ε), ρ ≈ 0.9. Old gradients are forgotten, so the denominator stays bounded and the learning rate does not vanish. It handles non-stationary objectives well and was the standard before Adam.

Q6Explain Adadelta. Why does it not need a learning rate?6 marks

Adadelta extends Adagrad by using decaying averages of squared gradients, E[g²], and of squared updates, E[Δθ²]. Update: Δθ = −[√(E[Δθ²]+ε)/√(E[g²]+ε)]·g, then θ ← θ + Δθ and E[Δθ²] is updated with the same decay ρ. The ratio of RMS(past updates) to RMS(gradients) plays the role of the learning rate (and makes units consistent), so no global α is set. It avoids Adagrad's vanishing rate; the cost is extra computation.

Q7Explain Adam with its update equations and default values.6 marks

m = β₁m + (1−β₁)g and v = β₂v + (1−β₂)g² are the first and second moment estimates. Bias-corrected: m̂ = m/(1−β₁ᵗ), v̂ = v/(1−β₂ᵗ). Update: θ ← θ − α·m̂/(√v̂ + ε). Defaults β₁ = 0.9, β₂ = 0.999, ε = 1e-8. It combines momentum and RMSprop, so it is fast, needs little tuning and is the usual default; the cost is two extra stored values per weight.

Q8Why does Adam use bias correction? Show the first step for g = 2.4 marks

m and v start at 0, so early estimates are biased toward 0 (especially v with β₂ = 0.999). Dividing by (1−βᵗ) removes that bias. For g = 2 at t = 1: m = 0.2, v = 0.004; m̂ = 0.2/0.1 = 2, v̂ = 0.004/0.001 = 4; step = α·2/√4 = α. Without correction the step would be about 3.2α.

Q9How would you choose an optimizer? Give a comparison of Adagrad, RMSprop, Adadelta and Adam.5 marks

For sparse data prefer adaptive methods (Adagrad, Adadelta, RMSprop, Adam). Adagrad: sum of squares, rate decays. RMSprop: decaying average, needs base α. Adadelta: no α, ratio of averages. Adam: RMSprop + momentum + bias correction, and better than RMSprop as gradients get sparse. Default to Adam/AdamW; SGD with momentum is still common for CNNs. Always tune α for each optimizer separately.

Group B

Batch normalization

Unit 4 Q10–15 · Beyond the deck: standard content

Q10What is batch normalization and why is it used?4 marks

A layer that normalizes each feature over the mini-batch to zero mean and unit variance, then applies a learnable scale γ and shift β. It keeps layer inputs in a stable range as earlier layers change (the original "internal covariate shift" motivation), which allows higher learning rates and faster, more stable training.

Q11Write the batch normalization equations.5 marks

μ_B = (1/m)Σxᵢ; σ²_B = (1/m)Σ(xᵢ − μ_B)²; x̂ᵢ = (xᵢ − μ_B)/√(σ²_B + ε); yᵢ = γx̂ᵢ + β. ε avoids division by zero; γ and β are learned by backpropagation and let the network recover the original distribution if that is best.

Q12Normalize the batch [2, 4, 6, 8] with γ = 2, β = 1 (ε = 1e-5).4 marks

μ = 5, σ² = (9+1+1+9)/4 = 5, √(σ²+ε) ≈ 2.236. x̂ ≈ [−1.342, −0.447, 0.447, 1.342]. y = 2x̂ + 1 ≈ [−1.683, 0.106, 1.894, 3.683].

Q13How does batch norm behave at training time versus inference time?4 marks

Training: uses the current batch's μ_B and σ²_B, while also updating running averages (μ_run ← λμ_run + (1−λ)μ_B, likewise for variance). Inference: the batch may be one sample, so the stored running mean and variance are used, making the output deterministic. γ and β are learned parameters in both modes.

Q14List the benefits and limitations of batch normalization.4 marks

Benefits: faster convergence, higher learning rates, less sensitivity to initialization, eases vanishing/exploding gradients, slight regularization from batch noise. Limitations: poor with very small batches, extra train/inference mismatch, awkward for RNNs. Alternatives: Layer Norm (Transformers) and Group Norm.

Q15Why are γ and β needed after normalizing?3 marks

Forcing every layer to exactly zero mean and unit variance would reduce its representational power (e.g. it confines a sigmoid to its linear region). γ and β let the layer learn the best scale and offset, including the identity transform if normalization is not helpful.

Group C

Exploding and vanishing gradients

Unit 4 Q16–21 · Beyond the deck: standard content

Q16What are vanishing and exploding gradients?4 marks

In a deep network the gradient reaching early layers is a product of many per-layer factors (chain rule). If the factors are mostly below 1 the product tends to 0, so early layers stop learning (vanishing); if mostly above 1 it grows without bound, causing huge updates and NaN loss (exploding).

Q17What causes them?4 marks

Saturating activations (sigmoid′ ≤ 0.25, tanh at its tails), poor weight initialization (too small or too large), great depth, and in RNNs the repeated multiplication by the same weight matrix over many time steps. Example: 0.25¹⁰ ≈ 9.5×10⁻⁷ while 1.5¹⁰ ≈ 57.7.

Q18How can vanishing gradients be mitigated?5 marks

Use ReLU-family activations (derivative 1 for positive inputs), He/Xavier initialization, batch normalization, residual (skip) connections where y = x + F(x) so ∂y/∂x = 1 + ∂F/∂x, and in RNNs gated cells (LSTM/GRU).

Q19Explain gradient clipping.3 marks

If the gradient norm exceeds a threshold τ, rescale it: g ← g·τ/‖g‖. This preserves direction but bounds the step. Example: ‖g‖ = 10, τ = 5 multiplies g by 0.5. Standard for training RNNs and Transformers.

Q20Compare Xavier and He initialization.4 marks

Both choose weight variance to keep activations and gradients at a similar scale across layers. Xavier/Glorot: Var(w) = 2/(n_in + n_out), suited to sigmoid/tanh. He: Var(w) = 2/n_in, accounting for ReLU zeroing half the units. Example: n_in = 100 gives He std = √0.02 ≈ 0.141.

Q21How do LSTM gates and residual connections help gradient flow?4 marks

An LSTM updates its cell state additively, c_t = f⊙c_{t−1} + i⊙c̃_t, so with the forget gate near 1 the gradient flows back through time almost unchanged. A residual block adds an identity path, so the gradient has a direct route to early layers regardless of what F does. Both replace long products of small factors with a near-constant path.

Group D

Hyperparameter tuning and interpretability

Unit 4 Q22–28 · Beyond the deck: standard content

Q22What are hyperparameters? Name the important ones for a deep network.3 marks

Settings chosen before training rather than learned: learning rate (most important), batch size, number of epochs, optimizer and its β/ρ values, network depth and width, activation, dropout rate, weight decay. Weights and biases are parameters, learned by gradient descent.

Q23Compare grid search and random search.5 marks

Grid search tries every combination of a fixed grid; 3 learning rates × 3 batch sizes × 2 dropouts = 18 runs, and the count grows exponentially with the number of hyperparameters. Random search samples each one from a distribution; since usually only a few hyperparameters matter, it tries many more distinct values of those for the same budget and generally finds better settings.

Q24Explain Bayesian optimization for hyperparameter tuning.4 marks

It fits a probabilistic surrogate (e.g. a Gaussian process) to the validation score observed so far, then uses an acquisition function to choose the next configuration, balancing exploration of uncertain regions and exploitation of promising ones. It needs far fewer trials, which matters when each training run is costly.

Q25Describe the correct validation protocol for tuning.4 marks

Split data into train, validation and test sets. Fit weights on train, compare hyperparameters on validation, and evaluate the final chosen model once on test; tuning on the test set leaks information and inflates results. With little data use k-fold cross-validation, and average over several seeds.

Q26How do the learning rate and batch size affect training?4 marks

Too small a learning rate converges slowly; too large oscillates or diverges, so search it on a log scale (about 1e-5 to 1e-1) and use a schedule. A larger batch gives smoother gradients and better hardware use but needs more memory and may generalize worse; a smaller batch adds helpful noise but more variance. Typical batch sizes are 32–256.

Q27What is interpretability? Explain Grad-CAM, LIME and SHAP briefly.6 marks

Interpretability is explaining why a model gave a prediction. Grad-CAM weights a conv layer's feature maps Aᵏ by αₖ = mean of ∂yᶜ/∂Aᵏ and shows ReLU(Σαₖ Aᵏ) as a heatmap of the regions that drove class c. LIME perturbs one input, queries the model and fits a simple local linear model whose coefficients are the explanation. SHAP gives each feature its Shapley value φᵢ, with f(x) = baseline + Σφᵢ, so attributions are additive and consistent.

Q28Explain saliency maps and feature visualisation, and discuss the accuracy vs explainability trade-off.5 marks

A saliency map is the gradient of the class score with respect to the input pixels: large magnitude means the output is sensitive to that pixel. Feature visualisation optimizes an input to maximally activate a chosen neuron or channel, showing what it detects. Linear models and shallow trees are transparent but often less accurate; deep nets are accurate but opaque. Post-hoc explanations are approximations and can mislead, so they should be validated.
