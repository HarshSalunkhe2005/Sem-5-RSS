Architecture: Input layer 784 neurons (28×28 pixel images) → Hidden Layer 1: 128 neurons → Hidden Layer 2: 64 neurons → Output layer: 10 neurons (digits 0–9).Hidden 1: weights = 784×128 = 100,352 biases = 128 Hidden 2: weights = 128×64 = 8,192 biases = 64 Output: weights = 64×10 = 640 biases = 10 Total weights = 109,184 Total biases = 202

Q4bFind out the trainable parameters in the following CNN model in every step:3 marks

1. my_input = Input(Shape=(10,10,1)) 2. my_output = Convolution2D(5,3)(my_input) 3. my_output = Activation('Sigmoid')(my_output) 4. my_output = Convolution2D(2,3)(my_output) 5. my_output = Activation('Sigmoid')(my_output)Step 2: 5 filters × (3×3×1 weights + 1 bias) = 5×10 = 50 trainable params.
Step 4: 2 filters × (3×3×5 weights + 1 bias) = 2×46 = 92 trainable params.
Activation steps (3, 5) add no trainable parameters.
