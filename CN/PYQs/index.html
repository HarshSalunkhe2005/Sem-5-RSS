Q4A host IP address is 193.27.100.110/26. Determine (a) the subnet address, (b) the directed broadcast address for the subnet, (c) the maximum number of possible hosts on the subnet, (d) the maximum number of possible subnets.6 marks

/26 → 26 network bits, 6 host bits → block size = 256 − 192 = 64 193.27.100.110 falls in the subnet 193.27.100.64 – 193.27.100.127 a) Subnet address: 193.27.100.64 b) Directed broadcast address: 193.27.100.127 c) Max hosts per subnet: 2^6 − 2 = 62 d) Max subnets (from the /24 block, borrowing 2 bits for /26): 2^2 = 4

Q3You applied cyclic redundancy check (CRC) using the dataword 1001 and the divisor 1011, and generated a codeword. However, during transmission, the received codeword is 1001110. Does the received codeword contain any errors?6 marks

Divide the received codeword 1001110 by the divisor 1011 using modulo-2 (XOR) division. A non-zero remainder means the codeword contains a transmission error and should be rejected.

Q1bDuring the TCP slow start phase, if a sender transmits 2 segments and receives 2 ACKs, how many segments will it be able to send in the next round-trip time (RTT)?2 marks

Slow start doubles cwnd each RTT. Sent 2, both ACKed → cwnd grows 2 → 4. It can send 4 segments in the next RTT.
