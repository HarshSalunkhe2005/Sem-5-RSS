Numerical 1

UDP / checksum calculation (one's complement)

Data words (4-bit each): 7, 11, 12, 0 → binary: 0111, 1011, 1100, 0000
  • Add first two words (one's-complement addition)0111 + 1011 = 1 0010 → wraps: 0010 + 1 (carry) = 0011
  • Add the running sum + third word0011 + 1100 = 1111
  • Add the running sum + fourth word1111 + 0000 = 1111
  • Checksum = one's complement of the sumcomplement(1111) = 0000
    • Checksum sent = 0000

    Receiver-side check

  • Add all 4 data words + the received checksum0111+1011+1100+0000+0000 → same steps as above → 1111
  • Complement the resultcomplement(1111) = 0000
    • Result = 0000 → all zeros → data accepted (no error detected)

    The rule: if the complement of (data + checksum) comes out to all zeros, the receiver accepts the data. Any 1 bit in that result means something got corrupted in transit.

    Numerical 2

    Go-Back-N efficiency

    Window size N = 4, Propagation Delay (Tp) = 20 ms, Transmission Delay (Tt) = 5 ms
  • Compute aa = Tp / Tt = 20 / 5 = 4
  • Apply the GBN efficiency formulaEfficiency = N / (1 + 2a) = 4 / (1 + 8) = 4 / 9
    • Efficiency ≈ 0.444 = 44.4%

    Notice how a large a (propagation delay dominating transmission delay — e.g. a satellite link) crushes efficiency; this is exactly why bigger windows (bigger N) matter more on high-delay links.

    Numerical 3

    Stop-and-Wait timing (propagation, RTT, timeout, TTL)

    Distance between routers = 1000 km, propagation speed = 2×10⁸ m/s
  • Propagation Delay= Distance / Velocity = 1,000,000 m / (2×10⁸ m/s) = 5 ms
  • Round Trip Time (RTT)≈ 2 × Propagation Delay (data there + ack back) = 2 × 5 ms = 10 ms
  • Timeout (TO)= 2 × RTT = 2 × 10 ms = 20 ms
  • Time To Live (TTL)= 2 × Timeout = 2 × 20 ms = 40 ms
    • Propagation Delay = 5 ms, RTT = 10 ms, Timeout = 20 ms, TTL = 40 ms

    Numerical 4

    Minimum sequence-number bits for GBN

    Sender window size N = 7 (i.e. protocol "GB7")
  • GBN constraint (receiver window WR = 1)Ws + WR ≤ ASN → minimum sequence numbers = N + 1 = 8
  • Bits required⌈log₂(N+1)⌉ = ⌈log₂(8)⌉ = 3
    • Minimum bits required = 3 (giving sequence numbers 0–7)
