01 · Memory for sequences

Recurrent Neural Networks: the Basics

Text, speech and time series are sequences: order matters and length varies. A feed-forward network sees a fixed-size input with no memory. A recurrent neural network (RNN) reads one element at a time and carries a hidden state h_t forward, a running summary of everything seen so far. The same weights are reused at every time step (parameter sharing).

The equations

h_t = tanh( W_xh x_t + W_hh h_(t-1) + b )      hidden state (new memory)
y_t = softmax( W_hy h_t + c )                  output at step t
h_0 = 0                                        usual initial state

Sizes: x_t ∈ ℝ^nx, h_t ∈ ℝ^nh, W_xh is nh×nx, W_hh is nh×nh, W_hy is V×nh for a V-way output. Unrolling the loop over T steps gives a deep network with T layers whose weights are all tied.

Input/output patterns

PatternUseWhich outputs are used
Many-to-oneSentiment, text classificationOnly the last h_T
Many-to-many (aligned)POS tagging, NER, language modelAn output y_t at every step
One-to-manyImage captioningGenerated sequence, fed back in
Many-to-many (encoder–decoder)Machine translationEncoder state seeds the decoder

Worked example: one forward step

nx = 2, nh = 2. W_xh = [[0.5, −0.3],[0.8, 0.2]], W_hh = [[0.1, 0.4],[−0.2, 0.3]], b = [0.1, −0.1], input x_t = [1, 2], previous state h_(t−1) = [0.5, −0.5].

  1. W_xh x_t = [0.5·1 − 0.3·2, 0.8·1 + 0.2·2] = [−0.1, 1.2]
  2. W_hh h_(t−1) = [0.1·0.5 + 0.4·(−0.5), −0.2·0.5 + 0.3·(−0.5)] = [−0.15, −0.25]
  3. Pre-activation z = [−0.1 − 0.15 + 0.1, 1.2 − 0.25 − 0.1] = [−0.15, 0.85]
  4. h_t = tanh(z) = [−0.149, 0.691]
  5. With W_hy = [[1, −1],[0.5, 0.5]] and c = 0: logits [−0.840, 0.271], softmax y_t = [0.248, 0.752]. Class 2 is predicted with probability 0.75.

Bidirectional RNNs (briefly)

A bidirectional RNN runs one RNN left-to-right and another right-to-left and concatenates their states, so h_t = [h_t→ ; h_t←] sees both past and future context. Good for tagging and classification where the whole sentence is available; not usable for left-to-right generation.

Total loss is the sum over steps: L = Σ_t L_t (cross-entropy between y_t and the target). BPTT unrolls the network and applies ordinary backpropagation; because weights are shared, the gradient for a weight matrix is the sum of its contributions from every time step.

∂L/∂W_hh = Σ_t Σ_(k≤t)  ∂L_t/∂y_t · ∂y_t/∂h_t · ( ∏_(i=k+1..t) ∂h_i/∂h_(i-1) ) · ∂h_k/∂W_hh

∂h_i/∂h_(i-1) = diag( 1 − h_i² ) · W_hh          (tanh' = 1 − tanh²)

The bracketed product is a chain of (t−k) Jacobians, each made of W_hh and a tanh-derivative term. This product is the root of both the vanishing and exploding gradient problems (next section).

Practical fixes

Truncated BPTT

Backpropagate only through the last K steps (e.g. 20–100) instead of the whole sequence. Cuts memory and compute; the hidden state is still carried forward, but gradients do not flow beyond the window.

Gradient clipping

If ‖g‖ exceeds a threshold τ, rescale g ← g · τ/‖g‖. Standard cure for exploding gradients. It does nothing for vanishing gradients.

03 · Why plain RNNs forget

The Vanishing (and Exploding) Gradient Problem

To learn that the word at step k affects the loss at step t, the gradient must travel back t−k steps, and it is multiplied by diag(1 − h_i²) · W_hh at each one:

∂h_t/∂h_k = ∏_(i=k+1..t)  diag(1 − h_i²) · W_hh
  • tanh' ≤ 1, and is near 0 when a unit saturates. If the largest singular value of W_hh times the tanh' term is below 1, the norm shrinks exponentially in (t−k): vanishing.
  • If it is above 1, the norm grows exponentially: exploding (NaNs, unstable training).

Numerically: a factor of 0.9 per step over 10 steps gives 0.9¹⁰ ≈ 0.35; over 50 steps ≈ 0.005. A factor of 0.25 (the maximum of the sigmoid derivative) over 10 steps gives ≈ 10⁻⁶. A factor of 1.5 over 10 steps gives ≈ 58.

Consequence: early inputs get almost no gradient, so the RNN learns short-range dependencies and effectively forgets long-range ones. Exploding gradients are fixed by clipping; vanishing gradients need architectural fixes (LSTM, GRU, residual/skip paths), good initialisation (orthogonal W_hh) or ReLU-style activations.

04 · Gated memory

LSTM: Long Short-Term Memory

An LSTM adds a separate cell state c_t, a memory "conveyor belt", and three gates (sigmoid outputs in 0–1) that control what is erased, written and exposed. Let [h_(t−1), x_t] be the concatenation and σ the sigmoid.

f_t = σ( W_f [h_(t-1), x_t] + b_f )       forget gate:  how much old memory to keep
i_t = σ( W_i [h_(t-1), x_t] + b_i )       input gate:   how much new content to write
g_t = tanh( W_g [h_(t-1), x_t] + b_g )    candidate memory (often written c̃_t)
c_t = f_t ⊙ c_(t-1) + i_t ⊙ g_t           cell state update  (⊙ = element-wise)
o_t = σ( W_o [h_(t-1), x_t] + b_o )       output gate:  how much memory to reveal
h_t = o_t ⊙ tanh( c_t )                   hidden state / output

Role of the memory cell, and why it fixes vanishing gradients

The cell update is additive: c_t = f_t ⊙ c_(t−1) + i_t ⊙ g_t. The gradient along the cell path is ∂c_t/∂c_(t−1) = f_t (element-wise), with no repeated multiplication by W_hh and no squashing derivative. When the network sets f_t ≈ 1 the gradient passes back almost unchanged, so information (and error signal) can persist across hundreds of steps. The gates are learned, so the model decides what to remember. A common trick is to initialise the forget-gate bias to 1.

Input x = 1, h_(t−1) = 0.5, c_(t−1) = 0.4. Each gate is written as (w_x, w_h, b): forget (0.5, 0.4, 0.1), input (0.6, −0.2, 0), candidate (0.9, 0.3, 0.1), output (0.7, 0.1, 0.2).

05 · The lighter gated unit

GRU: Gated Recurrent Unit

A GRU merges the cell and hidden state into one vector and uses only two gates.

z_t = σ( W_z [h_(t-1), x_t] + b_z )              update gate
r_t = σ( W_r [h_(t-1), x_t] + b_r )              reset gate
h̃_t = tanh( W_h [ r_t ⊙ h_(t-1), x_t ] + b_h )   candidate state
h_t = (1 − z_t) ⊙ h_(t-1) + z_t ⊙ h̃_t           blend of old and new

The update gate decides how much of the old state to keep (like forget + input tied together); the reset gate decides how much of the old state is used when forming the candidate. The convex combination keeps an additive path, so gradients also survive long spans.

Parameter counts

For input size nx and hidden size nh, one weight block is nh·(nh + nx) + nh = nh(nh + nx + 1). An RNN has 1 block, a GRU 3 (z, r, candidate), an LSTM 4 (f, i, g, o).

Choosing

Empirically LSTM and GRU perform similarly on most tasks. Start with a GRU when data or compute is limited or you want a quick baseline; choose an LSTM for very long dependencies or larger datasets where the extra output gate and separate cell help; use a plain RNN only for short sequences or as a teaching baseline.

06 · Why RNNs beat n-grams

RNNs vs. Traditional Language Models

A language model assigns P(w_1…w_T) = ∏ P(w_t | w_1…w_(t−1)). A traditional n-gram model approximates this by conditioning on only the last n−1 words using counts. An RNN LM computes P(w_t | h_(t−1)) with h summarising the whole history.

Embeddings are covered in Unit 3. RNN LMs are effective because they combine those dense word vectors with a recurrent memory. But they remain sequential and weak at very long range, which motivates attention and transformers in Unit 5.

07 · Where RNNs struggle

Limitations of RNNs in Long Sequence Modelling

  • Vanishing/exploding gradients: weak learning of long-range dependencies (plain RNNs fail after roughly 10–20 steps).
  • Information bottleneck: the whole past is squeezed into one fixed-size vector; in encoder–decoder models, a long source sentence is compressed into a single context vector.
  • Sequential computation: h_t needs h_(t−1), so time steps cannot be parallelised across the sequence; training is slow on long inputs and GPUs are under-used.
  • Memory cost of BPTT: activations for all T steps must be stored (hence truncated BPTT).
  • Recency bias / forgetting: even LSTMs and GRUs slowly lose very distant information.
  • Distance between related tokens: information must pass through every intermediate step, so the path length is O(T). Attention shortens it to O(1).

Remedies: gated cells (LSTM/GRU), gradient clipping, truncated BPTT, bidirectional encoders, and above all attention/transformers (Unit 5).

08 · Putting it together

Designing an RNN-Based Sequence Model

  1. Understand the data: sequence length, vocabulary, label type (one label per sequence, per token, or next token).
  2. Tokenise and build a vocabulary: words or sub-words, with special tokens <PAD>, <UNK>, <BOS>/<EOS>. Map each token to an integer id; pad or bucket to equal length and mask the padding.
  3. Embedding layer: V×d lookup table, learned from scratch or initialised from pre-trained Word2Vec/GloVe (see Unit 3).
  4. Recurrent layer(s): RNN, LSTM or GRU; one or two layers; optionally bidirectional; add dropout between layers.
  5. Output layer: softmax over V for a language model; softmax/sigmoid over classes for sentiment (on the last state or a pooled state); softmax over tags at every step for tagging.
  6. Loss and optimiser: cross-entropy (ignore padded positions); Adam; gradient clipping (e.g. norm 1–5); truncated BPTT for long inputs.
  7. Evaluate: accuracy/F1 for classification and tagging, perplexity for language models; tune hidden size, layers, dropout, learning rate on a validation set.

Language model

Input: tokens w_1…w_(t−1). Target: the same sequence shifted by one. Output: softmax over V at every step. Metric: perplexity.

Sentiment analysis

Many-to-one. Embedding → (Bi)LSTM/GRU → last state → dense → sigmoid or softmax. Metric: accuracy/F1.

Sequence tagging (POS/NER)

Many-to-many. Embedding → BiLSTM → a softmax over tags at every token. Metric: token accuracy, entity F1.

Parameter budget example

V = 10,000, d = 100, one LSTM with nh = 128, softmax over V: embedding 10,000·100 = 1,000,000; LSTM 4·128·(100+128+1) = 117,248; output layer 128·10,000 + 10,000 = 1,290,000. Total ≈ 2.41 million. The embedding and softmax layers dominate, not the recurrent cell.
