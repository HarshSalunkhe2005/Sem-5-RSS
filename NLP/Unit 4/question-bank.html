Unit 4: Recurrent Neural Networks (CO4)

Symbiosis Institute of Technology — Course TEE7101

Q1Apply RNN for sequence prediction and interpret the output. [8M]

Task: predict the next item (word, character or value) from the items so far. At each step the RNN does h_t = tanh(W_xh x_t + W_hh h_(t−1) + b) and y_t = softmax(W_hy h_t + c), where y_t is a probability distribution over the possible next items.

Worked step: with W_xh = [[0.5,−0.3],[0.8,0.2]], W_hh = [[0.1,0.4],[−0.2,0.3]], b = [0.1,−0.1], x_t = [1,2], h_(t−1) = [0.5,−0.5]: pre-activation [−0.15, 0.85], so h_t = [−0.149, 0.691]. With W_hy = [[1,−1],[0.5,0.5]], logits are [−0.840, 0.271] and y_t = [0.248, 0.752].

Interpretation: the model assigns 75.2% to class/word 2 and 24.8% to class/word 1, so the prediction is the argmax (item 2), and the confidence is 0.752. The hidden state h_t is the memory passed to the next step. During training, loss = −log of the probability given to the true item (−log 0.752 ≈ 0.285 if item 2 was correct). For text, a good model gives the true next word high probability, so perplexity is low.

Q2Analyze the vanishing gradient problem in RNNs. [8M]

Backpropagation through time sends the error from step t back to step k through ∂h_t/∂h_k = ∏_(i=k+1..t) diag(1 − h_i²) · W_hh, a product of t−k Jacobians. The tanh derivative is at most 1 (and near 0 for saturated units), so when the dominant singular value of W_hh times that derivative is below 1, the product shrinks exponentially with distance: 0.9¹⁰ ≈ 0.35, 0.9⁵⁰ ≈ 0.005.

Effect: early time steps receive almost no gradient, so the network cannot learn long-range dependencies (e.g. subject–verb agreement across a long clause); it behaves as if it had a short memory. If the factor is above 1 the gradient explodes (1.5¹⁰ ≈ 58), fixed by gradient clipping.

Remedies: LSTM/GRU (additive, gated state paths), orthogonal initialisation of W_hh, ReLU-type activations, skip connections, truncated BPTT, and ultimately attention.

Q4Given a sequence dataset, design an RNN-based model. [10M]

  1. Analyse the data: sequence lengths, vocabulary size V, and the target (one label per sequence, per token, or next token).
  2. Preprocess: tokenise, build a vocabulary with <PAD>/<UNK>, convert to ids, pad/bucket and mask; split train/validation/test.
  3. Embedding layer (V×d, learned or pre-trained Word2Vec/GloVe from Unit 3).
  4. Recurrent layer: LSTM or GRU (one or two layers, optionally bidirectional, with dropout).
  5. Output layer: softmax over V (language model), softmax/sigmoid over classes taken from the last state (sentiment), or softmax over tags at each step (tagging).
  6. Training: cross-entropy loss ignoring padding, Adam, gradient clipping, truncated BPTT for long inputs, early stopping.
  7. Evaluation: accuracy/F1 or perplexity on held-out data; tune hidden size, layers, dropout.

Example: movie-review sentiment, V = 20,000, d = 100, one BiGRU of 64 units, dense sigmoid output.

Q5Analyze the role of memory cells in LSTM. [8M]

The cell state c_t is the LSTM's long-term memory, a vector that runs through time with only small, gated linear interactions: c_t = f_t ⊙ c_(t−1) + i_t ⊙ g_t.

  • Forget gate f_t erases parts of the old memory; input gate i_t decides how much of the candidate g_t to write; output gate o_t decides how much of tanh(c_t) to expose as h_t = o_t ⊙ tanh(c_t).
  • The update is additive, so ∂c_t/∂c_(t−1) = f_t: with f_t ≈ 1 the gradient flows back almost unchanged, which counters vanishing gradients and lets the cell hold information (a quote opening, a subject's number) over many steps.
  • Because c_t is separate from h_t, the cell can store information without it being output at every step.

Worked step (nx=nh=1): f=0.690, i=0.622, g=0.818, c_(t−1)=0.4 gives c_t = 0.690·0.4 + 0.622·0.818 = 0.785.

Q6Evaluate the effectiveness of RNNs over traditional language models. [8M]

Strengths of RNN LMs: (1) no fixed context window: the hidden state summarises the whole history, unlike n-grams that see only n−1 words; (2) parameters are shared across time and do not grow exponentially with context (n-grams need up to V^n entries); (3) dense embeddings let them generalise to unseen word combinations, avoiding the zero-count/smoothing problem; (4) typically lower perplexity; (5) compact model.

Weaknesses: training and inference are sequential and slower than counting; need more data and compute; hidden state is hard to interpret; plain RNNs still struggle with very long dependencies (needs LSTM/GRU); fixed-size state is a bottleneck.

Verdict: RNNs (especially LSTM/GRU) are clearly more effective in accuracy and generalisation; n-grams remain useful as fast, simple baselines. Transformers (Unit 5) have since overtaken RNNs for long contexts.

Q7Given a problem, select between RNN, LSTM and GRU with justification. [8M]

  • Plain RNN: short sequences (about 10–20 steps), tiny data or hardware, a teaching baseline. E.g. predicting the next character in short fixed-format codes.
  • GRU: moderate sequence length, limited data or compute, need fast training or deployment on small devices. E.g. sentiment of short tweets, real-time keyword spotting.
  • LSTM: long dependencies, large datasets, tasks needing precise memory control. E.g. document-level classification, machine translation encoder, time series with long seasonal lags, language modelling.

If unsure, try GRU first (cheaper), then LSTM; compare on a validation set. If the sequences are very long (hundreds to thousands of tokens) and parallel hardware is available, consider attention/transformers instead.

Q8Analyze limitations of RNNs in long sequence modeling. [8M]

  • Vanishing/exploding gradients hinder learning of long-range dependencies (plain RNNs fail beyond roughly 10–20 steps).
  • Fixed-size bottleneck: the whole past (or the whole source sentence in encoder–decoder models) is compressed into one vector.
  • No parallelism over time: h_t depends on h_(t−1), so training is slow on long sequences.
  • BPTT memory cost grows with sequence length (hence truncated BPTT, which in turn cuts off long-range credit assignment).
  • Gradual forgetting even in LSTM/GRU; information path length between distant tokens is O(T).

Fixes: gating (LSTM/GRU), clipping, truncated BPTT, bidirectionality, and attention/transformers (Unit 5), which connect any two positions in one step.

Applied Practice

RNN Basics, BPTT & Vanishing Gradients

Q9Define a recurrent neural network and write its forward equations. [5M]

An RNN is a neural network for sequential data that keeps a hidden state which is updated at every time step and fed back into the next step, using the same weights each time.

h_t = tanh(W_xh x_t + W_hh h_(t−1) + b), y_t = softmax(W_hy h_t + c), with h_0 = 0.

Q10What does "unrolling" an RNN mean? How many parameters does a vanilla RNN layer with nx = 10 inputs and nh = 20 hidden units have? [5M]

Unrolling draws the recurrence as a feed-forward chain with one copy of the cell per time step; all copies share the same weights, so a sequence of length T becomes a T-layer network with tied parameters.

Parameters (recurrent layer only) = W_xh (20×10 = 200) + W_hh (20×20 = 400) + b (20) = 620, i.e. nh(nx+nh+1). The count is independent of sequence length. An output layer to V classes would add nh·V + V.

Q11Numerical: compute one RNN step. nx = 2, nh = 2, W_xh = [[0.5,−0.3],[0.8,0.2]], W_hh = [[0.1,0.4],[−0.2,0.3]], b = [0.1,−0.1], x_t = [1,2], h_(t−1) = [0.5,−0.5]. Find h_t. [5M]

W_xh x_t = [0.5 − 0.6, 0.8 + 0.4] = [−0.1, 1.2]; W_hh h_(t−1) = [0.05 − 0.2, −0.1 − 0.15] = [−0.15, −0.25].

z = [−0.1 − 0.15 + 0.1, 1.2 − 0.25 − 0.1] = [−0.15, 0.85], so h_t = tanh(z) = [−0.149, 0.691].

Q12What is Backpropagation Through Time? Write the gradient of the loss with respect to W_hh. [6M]

BPTT unrolls the RNN over the sequence and applies backpropagation to the unrolled graph. Because weights are shared, gradients from every time step are summed. With L = Σ_t L_t:

∂L/∂W_hh = Σ_t Σ_(k≤t) (∂L_t/∂y_t)(∂y_t/∂h_t) (∏_(i=k+1..t) ∂h_i/∂h_(i−1)) (∂h_k/∂W_hh), where ∂h_i/∂h_(i−1) = diag(1 − h_i²) W_hh.

The long product is why gradients vanish or explode over many steps.

Q13Explain truncated BPTT and gradient clipping. When is each used? [5M]

Truncated BPTT: split the long sequence into chunks of K steps (e.g. 35); carry the hidden state across chunks but backpropagate only inside the current chunk. It limits memory/compute, but gradients cannot cross chunk boundaries.

Gradient clipping: if the gradient norm ‖g‖ exceeds a threshold τ, replace g with τ·g/‖g‖. It prevents exploding gradients and keeps updates stable; it does not cure vanishing gradients.

Q14Numerical: the gradient is multiplied by an average factor of 0.8 per time step. What fraction remains after 20 steps? What if the factor is 1.2? [4M]

0.8²⁰ ≈ 0.0115 (about 1% of the signal remains: vanishing). 1.2²⁰ ≈ 38.3 (the gradient is 38 times larger: exploding).

This is why a signal from 20 steps back is almost lost in a plain RNN, and why clipping is needed for the other case.

Applied Practice

LSTM & GRU

Q15Write the equations of an LSTM cell and state the purpose of each gate. [6M]

f_t = σ(W_f[h_(t−1), x_t] + b_f) forget: how much of c_(t−1) to keep.
i_t = σ(W_i[h_(t−1), x_t] + b_i) input: how much new information to write.
g_t = tanh(W_g[h_(t−1), x_t] + b_g) candidate memory content.
c_t = f_t ⊙ c_(t−1) + i_t ⊙ g_t cell update.
o_t = σ(W_o[h_(t−1), x_t] + b_o) output: how much of the cell to expose.
h_t = o_t ⊙ tanh(c_t) new hidden state.

Q16Numerical: one LSTM step with nx = nh = 1, x = 1, h_(t−1) = 0.5, c_(t−1) = 0.4. Gate parameters (w_x, w_h, b): f (0.5, 0.4, 0.1), i (0.6, −0.2, 0), g (0.9, 0.3, 0.1), o (0.7, 0.1, 0.2). Find c_t and h_t. [6M]

f = σ(0.5 + 0.2 + 0.1) = σ(0.8) = 0.690
i = σ(0.6 − 0.1 + 0) = σ(0.5) = 0.622
g = tanh(0.9 + 0.15 + 0.1) = tanh(1.15) = 0.818
o = σ(0.7 + 0.05 + 0.2) = σ(0.95) = 0.721

c_t = 0.690·0.4 + 0.622·0.818 = 0.276 + 0.509 = 0.785
h_t = 0.721 · tanh(0.785) = 0.721 · 0.656 = 0.473

Q17Numerical: for nx = 100 and nh = 128, find the number of parameters in a vanilla RNN, a GRU and an LSTM layer. [5M]

One weight block = nh(nx + nh + 1) = 128 × 229 = 29,312.

Vanilla RNN: 1 block = 29,312. GRU: 3 blocks (update, reset, candidate) = 87,936. LSTM: 4 blocks (forget, input, candidate, output) = 117,248.

Ratio RNN : GRU : LSTM = 1 : 3 : 4. (Libraries that use two bias vectors per gate add a few more.)

Q18Write the GRU equations and explain the update and reset gates. How does a GRU differ from an LSTM structurally? [6M]

z_t = σ(W_z[h_(t−1), x_t] + b_z), r_t = σ(W_r[h_(t−1), x_t] + b_r),
h̃_t = tanh(W_h[r_t ⊙ h_(t−1), x_t] + b_h), h_t = (1 − z_t) ⊙ h_(t−1) + z_t ⊙ h̃_t.

Update gate z: how much of the state is replaced by the candidate (z≈0 keeps the old state, giving long memory). Reset gate r: how much past state is used to build the candidate (r≈0 ignores history).

Difference: a GRU has no separate cell state and no output gate, and it merges forget and input into one update gate, so it has fewer parameters.

Q19True or False: a GRU has a separate memory cell and three gates, like an LSTM. [2M]

False. A GRU has two gates (update and reset) and a single hidden state with no separate cell; the LSTM has three gates and a separate cell state.

Applied Practice

RNNs vs. Traditional Language Models, and Design

Q20What is a bidirectional RNN? Give one task where it helps and one where it cannot be used. [4M]

It runs one RNN forward and another backward over the input and concatenates the two states at each position, h_t = [h_t→ ; h_t←], so each token sees both left and right context.

Helps: POS tagging/NER, sentiment, and encoders in translation (the whole sentence is known). Cannot be used for: left-to-right text generation or real-time prediction, because future tokens are not available.

Q21A trigram language model over V = 10,000 words must store counts. Compare its storage and generalisation with an RNN LM. [6M]

The trigram model has up to V³ = 10¹² possible entries; most are never observed, so it relies on sparse tables plus smoothing/back-off, uses only the last 2 words, and gives zero or poor probability to unseen trigrams such as "purchase a laptop" if only "buy a laptop" was seen.

An RNN LM has a fixed number of parameters (embedding + recurrent weights + output layer, a few million), conditions on the entire history through h_t, and since "buy" and "purchase" have similar embeddings it generalises to the unseen phrase. The price is slower training and inference.

Q22Numerical: sentiment model with vocabulary 5,000, embedding size 50, one GRU of 64 units and a single sigmoid output. Count the trainable parameters. [6M]

  • Embedding: 5,000 × 50 = 250,000
  • GRU: 3 × 64 × (50 + 64 + 1) = 3 × 7,360 = 22,080
  • Output (64 weights + 1 bias): 65

Total = 272,145. The embedding layer dominates; freezing pre-trained embeddings (Unit 3) would leave only about 22,145 trainable parameters.
