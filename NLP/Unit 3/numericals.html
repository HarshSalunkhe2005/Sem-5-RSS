CBOW

Predicting "deep" from {like, learning}

Sentence: "I like deep learning" · window=1 · target="deep" · context={like, learning} · embedding dim=2 · learning rate η=0.1

Setup — Given embeddings

WordInput vector (W)Output vector (W′)
I[0.1, 0.2][0.1, 0.3]
like[0.4, 0.3][0.2, 0.4]
deep[0.2, 0.5][0.4, 0.1]
learning[0.6, 0.1][0.3, 0.2]

Step 1 — Forward pass: average context vectors

h = (v_like + v_learning) / 2

h = ([0.4,0.3] + [0.6,0.1]) / 2 = [1.0, 0.4] / 2 = [0.5, 0.2]

Step 2 — Score every word, then softmax

score(w) = h · u_w

score(I) = 0.5×0.1 + 0.2×0.3 = 0.11  ·  score(like) = 0.5×0.2 + 0.2×0.4 = 0.18
score(deep) = 0.5×0.4 + 0.2×0.1 = 0.22  ·  score(learning) = 0.5×0.3 + 0.2×0.2 = 0.19
e^0.11≈1.116, e^0.18≈1.197, e^0.22≈1.246, e^0.19≈1.209 → sum ≈ 4.768

learning0.191.20925.4%

Step 3 — Loss (cross-entropy for true word "deep")

L = −log P(deep) = −log(0.2613) ≈ 1.342
Error signal per word: e_w = P(w) − y(w) (y=1 only for "deep")
e_I = +0.234, e_like = +0.251, e_deep = −0.739, e_learning = +0.254

Step 4 — Backward pass: gradient & update

∂L/∂h = Σ eᵥ · u_w, then split evenly across the 2 context words.

∂L/∂h ≈ [−0.146, 0.147]
grad per context word = ∂L/∂h ÷ 2 = [−0.073, 0.074]
v_new = v_old − η·grad:
v_like: [0.4,0.3] − 0.1×[−0.073,0.074] = [0.407, 0.293]
v_learning: [0.6,0.1] − 0.1×[−0.073,0.074] = [0.607, 0.093]

Skip-gram

Predicting "like" from Target "deep"

Same sentence/embeddings as above · target "deep" generates 2 pairs: (deep,like) and (deep,learning) · this walkthrough covers pair (deep → like)

Step 1 — Forward pass: no averaging, use target's own vector

h = v_deep = [0.2, 0.5] (taken directly from W — Skip-gram skips CBOW's averaging step entirely)

Step 2 — Score every word, then softmax

score(I) = 0.2×0.1+0.5×0.3 = 0.17  ·  score(like) = 0.2×0.2+0.5×0.4 = 0.24
score(deep) = 0.2×0.4+0.5×0.1 = 0.13  ·  score(learning) = 0.2×0.3+0.5×0.2 = 0.16
e^0.17≈1.185, e^0.24≈1.271, e^0.13≈1.139, e^0.16≈1.174 → sum ≈ 4.768
Wordscoree^scoreP(w)
I0.171.18524.9%
like (true context)0.241.27126.7%
deep0.131.13923.9%
learning0.161.17424.6%

Step 3 — Loss for this one pair

L = −log P(like) = −log(0.2666) ≈ 1.322 (the (deep,learning) pair gets its own separate loss)

Step 4 — Backward pass: update the target vector

Unlike CBOW, the full gradient goes to v_deep alone — no splitting, since there was only one input word.

∂L/∂v_deep ≈ [0.048, −0.146]
v_deep: [0.2,0.5] − 0.1×[0.048,−0.146] = [0.195, 0.515]
u_like: [0.2,0.4] − 0.1×(−0.733)×[0.2,0.5] = [0.215, 0.437]
The (deep, learning) pair then repeats this whole process independently, producing its own gradient contribution to v_deep — both pairs' gradients accumulate before the next update.

GloVe

Building a Co-occurrence Matrix

Sentence: "Students train the model using data" · window = 2

Step 1–2: Tokenize & build vocabulary

Tokens: [Students, train, the, model, using, data] — 6 unique words, each frequency = 1.

Step 3: Co-occurrence matrix (window=2)

Cell (i,j) = how often word i and word j appear together within the window. For "the" (center of the sentence), context = {Students, train, model, using}.

Studentstrainthemodelusingdata
Students011000
train101100
the110110
model011011
using001101
data000110
"the" co-occurs with 4 other words — it sits at the center of this short sentence. "Students" and "data" never co-occur (cell = 0) — they're far apart in the sentence, so training will push their vectors apart, while "the"/"train"/"model" (frequent co-occurrence) get pulled close together.

Step 4–6: What training produces

GloVe adjusts every word vector so its dot product with another word's vector matches their observed co-occurrence count as closely as possible. After training, each vocabulary word gets one dense row in the final embedding matrix — e.g. (illustrative 3D): Students=[0.12,0.44,-0.08], train=[0.31,0.27,0.19], the=[0.29,0.31,0.22]. One sentence gives a weak signal; GloVe needs a huge corpus (6B+ tokens) for these statistics to become reliable.
